# Installer Plan

## User experience

`Charlie-MJ-Video-Downloader-Setup.exe`

1. Welcome
2. License
3. Install location
4. Components
   - Desktop app
   - Media engine
   - FFmpeg
   - Browser integration
5. Install
6. Finish
7. Optional "Open Browser Integration Setup"

## Distribution

For each release:

- Publish installer checksum.
- Publish release notes.
- Sign the Windows installer and application binaries.
- Pin and document yt-dlp/FFmpeg versions.
- Keep third-party licenses/notices.
- Test clean Windows 10/11 VMs.
